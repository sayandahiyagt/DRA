This is a deep research agent starting from general user grilling and ending up with detailed context ready documentation that can be handoffed to single/multiple orchestrator agent(s) for building. This is not a general purpose theory driven research tool, but a practical one, focussed on immediate coding implementation. 

General use cases:
- understanding open source code repositories to build forks, extensions, or specific narrow applications
- understanding academic papers for self testing and building implementation from theory
- taking inspiration from existing online media or documentation to build one's own similar creation
